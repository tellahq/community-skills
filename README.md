# Tella community skills

Agent skills for making videos, shared by Tella and the people who use it: motion graphics, edits and styles you can copy and make your own.

Each skill is a folder under [`skills/`](skills) with a `SKILL.md` and any files it needs, such as a reference video.

## Use one in Tella

Paste a skill's ID into the AI chat in any Tella video:

```
tellahq/community-skills/kaleidoscope
```

It's used in that chat only and doesn't go into your skill library. Ask Tella to save it when you want to keep it, with your changes.

## Use one in another agent

```
npx skills add tellahq/community-skills
```

Most skills drive Tella through its MCP server and build on Tella's own skills, so add those too: `npx skills add tellahq/skills`.

## Share a skill

Share your own from Tella: open a skill you wrote in your skill library and choose **Share with the community**. Each one is reviewed before it shows up here. This repo is a read-only copy, so pull requests here aren't read.
